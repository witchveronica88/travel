# 여행 페이지 만들기 가이드

이 저장소의 여행 페이지는 **폰에서 여행 중에 꺼내 보는 한 장짜리 앱**이다.
가장 공들인 기준 작품은 `istanbul/index.html`이고, `haenam/index.html`은 1박 2일 국내 버전이다.
새 페이지는 **이스탄불 파일을 복사해 데이터만 바꾸는 방식**으로 만든다. CSS와 렌더 코드를 새로 짜지 않는다. 그래야 UI가 똑같이 나온다.

---

## 1. 파일 구성

```
<여행지>/
  index.html   ← 모든 것이 들어 있는 단일 파일 (CSS·JS·데이터·사진)
  icon.svg     ← 바로가기 아이콘. 그 여행지를 상징하는 단순한 실루엣 하나 (이스탄불=모스크, 해남=닻)
```

- 폴더 이름은 영문 소문자 (`istanbul`, `haenam`, `jeju`, `kyoto` …).
- 사진은 **base64로 HTML 안에 넣는다**. 여행지에서 데이터가 약해도 열리게 하기 위해서다. 사진 하나는 긴 변 900~1200px 정도의 JPEG로 줄여서 넣는다.
- 외부 스크립트나 폰트에 의존하지 않는다. 오프라인에서도 전부 동작해야 한다.
- `<title>`은 여행지 이름. `icon.svg`를 `rel="icon"`과 `rel="apple-touch-icon"` 둘 다에 연결해 홈 화면 추가가 되게 한다.

## 2. 전체 UI 뼈대

- 모바일 우선, 본문 최대 폭 **560px**, 좌우 여백 16px, 아이폰 안전 영역(`env(safe-area-inset-*)`) 처리.
- **하단 고정 탭 5개** (아이콘 + 글자):
  - 긴 여행: `일정 · 장소 · 맛집 · 정보 · 준비` (이스탄불)
  - 1박 2일 같은 짧은 여행: `첫째날 · 둘째날 · 장소 · 맛집 · 체크` (해남, 날짜를 탭으로 바로 노출)
- 라이트/다크 모드 둘 다 지원 (`prefers-color-scheme`).
- 색: 배경 `#EDEFF2`, 흰 카드 + 옅은 테두리 `#DDE1E6` + 아주 옅은 그림자. 강조색은 **청록 `#0D6B6B`** (다크 `#4DB6B6`). 강조색은 여행지에 맞게 바꿔도 되지만 한 가지만 쓴다.
- 글꼴: Pretendard → Apple SD Gothic Neo → Noto Sans KR. `word-break: keep-all`.
- 글자 크기는 몇 단계로만 제한한다: 본문 16 / 보조 14 / 날짜·작은 라벨 12~14 / 큰 제목 21 / 날짜 큰 숫자 34. 중간 크기를 새로 만들지 않는다.
- 탭별 스크롤 위치를 기억한다.

## 3. 일정 화면 — 가장 중요한 부분

### 3-1. 날 머리

1. **날짜 스트립**: 맨 위에 모든 날짜를 요일+숫자 버튼으로 나열. 선택된 날은 강조색으로 채우고, **토·일은 빨간색**.
2. **날짜 블록 + 제목**: 왼쪽에 `2026.10 / 25 / 일요일` 세로 블록, 오른쪽에 그날 제목과 부제.
   - 제목은 그날의 테마: `베이올루와 쥐쿠르주마`, `유럽에서 아시아로`, `카디쾨이 먹거리 산책`
   - 부제는 **핵심 시각만 뽑은 요약**: `09:00 세인트 안투안 성당 · 11:00 SALT 베이올루 · 12:30 탄투니`
3. 맨 아래에 `‹ 10/24` `10/26 ›` 이전/다음 날 버튼, 그 위에 그날 해당하는 **"이동 정보"** 접는 상자 (공항 가는 법, 교통카드 등).

### 3-2. 카드 – 이동 – 카드 동선 (핵심 형식)

하루는 **장소 카드 → 이동 칩 → 장소 카드 → 이동 칩 …** 으로 세로로 흐른다.

```
┌────────────────────────────┐
│ [사진]                      │
│ 09:00  세인트 안투안 성당  (i)(📍) │
│ ─────────────────────────── │
│ 체류 시간  45분              │
│ 메모      일요일 10:00 미사 전에 조용히 둘러본다. │
│ 함께 보기  이스티클랄 거리 · 탁심 광장 │
└────────────────────────────┘
            ┊
   ( 09:55 출발 · 도보 5분 · 약 400m )      ← 이동 칩
            ┊
┌────────────────────────────┐
│ 10:00  아스말르메스짓 골목 산책 …       │
```

- 카드 사이는 **세로 점선**(`--journey-line`)으로 잇고, 가운데에 둥근 알약 모양 **이동 칩**을 둔다.
- 이동 칩 문장은 항상 **`{출발 시각} 출발 · {수단과 경로} · {소요 시간} · {거리}`** 순서다.
  - `08:40 출발 · 호텔에서 이스티클랄 방면 도보 15~20분 · 약 1.1km`
  - `09:30 출발 · 호텔→탁심 도보 15~20분 → M2 베즈네질레르 7분 → 오르막 도보 12분 · 열차 대기 포함 총 40~55분`
  - `13:55 출발 · 언덕을 넘어 도보 30분 안팎 · 약 2km · 오르막 포함 (택시 10분)`
  - 국내 렌터카: `09:50 출발 · 차 50분`
- 환승은 `→`로 잇고, 구간마다 시간을 붙인다. **대기 시간 포함 총 소요**를 범위로 적는다.
- 오르막/내리막, 택시 대안, 막차·셔틀 시각처럼 **실제로 걸리는 제약**을 칩이나 메모에 꼭 적는다.
- 시각 계산이 맞아야 한다: `다음 카드 시각 ≈ 출발 시각 + 이동 시간`, `출발 시각 ≈ 이전 카드 시각 + 체류 시간`.
- 페리·예배·노을처럼 시각이 유동적인 뒤쪽 일정은 `도착 직후`, `모스크 후`, `페리 시각에 맞춰`처럼 **상대 시각**으로 쓴다.

### 3-3. 장소 카드 안쪽

- 맨 위 **사진**: 1장(가로로 길게 16:5), 2장(나란히), 3장(위 1장 크게 + 아래 2장).
- 머리줄: **큰 굵은 시각**(18px) + 제목 + 오른쪽 **원형 아이콘 버튼 2개** — ⓘ 장소 설명(카드 안에서 펼침), 📍 지도.
- 아래 표(dl): `가는 길`, `체류 시간`, `메모` — 있는 것만.
- **함께 보기**: 관련 장소·음식 이름을 `·`로 나열하고, 누르면 카드 안에서 그 설명이 펼쳐진다 (페이지 이동 없음).
- 끼니 카드는 제목을 **`점심: 식당명`**, **`간식: …`** 처럼 쓰고, 카페·디저트도 하나의 정류장으로 넣는다.
- 아직 식당을 못 정한 끼니는 `점심 예정`으로 쓰고 **빨간 제목**(해남의 `chg`)으로 표시, 메모에 `후보: A - 대표 메뉴. 대기가 길면 B로.`
- 하루의 처음과 끝은 숙소(`호텔 아침`, `호텔 도착`). 숙소 이름은 본문에서 강조색으로 표시한다.
- 지도 링크: 해외는 구글 지도(현지어 장소명으로 검색), 국내는 네이버 지도.

### 3-4. 일정 짜는 방식 (내용 면)

- 하루 장소는 **4~9곳**. 도보로 이어지는 동네 단위로 묶는다. 하루 한 지역/테마.
- 무리하지 않는다: 도착 다음 날은 늦게 시작, 중간에 카페·차이로 쉬는 칸을 넣는다.
- 무료 명소(도서관·공원·모스크·시장·동네 산책) 위주, 유료는 꼭 볼 곳만 하루에 모아서.
- 요일·공휴일·휴무·운영 시작 시각·셔틀 시간표를 반영해 순서를 정하고, 그 이유를 메모에 적는다.
  예) `호텔 셔틀은 10:00부터 운행해 09:30 출발에는 탈 수 없어 도보와 지하철로 간다.`
- 예매가 끝난 건 `예매 완료`, 좌석 번호까지 적는다.

## 4. 장소 탭

그룹별 접는 카드 목록 (예: 도서관 / 공원 / 거리·동네 / 모스크·시장 / 쇼핑 / 유료 명소).
요약 줄: 작은 사진 썸네일 + 이름 + **일정에 들어간 날짜 배지**(`10/25`) + 부제(현지어 이름 또는 동네) + 오른쪽 지도 원형 버튼. 별점(★1~5)을 데이터로 가진다.

펼친 본문 순서는 고정:

1. 사진
2. **한 줄 소개**
3. **어떤 곳**
4. **재미있는 이야기** (2~3개)
5. **아이 미션** — 아이가 현장에서 해 볼 작은 과제 (`창밖 전망에서 바다와 두 대륙을 찾아본다.`)
6. **정보 표** — 주소 · 운영 · 요금 · 전화 · 가는 법 · 머무는 시간
7. **주의할 점**
8. 유료면 비용 한 줄, 마지막에 지도 보기

## 5. 맛집 탭

- **지역별 그룹**(그룹 이름 아래 작은 설명 한 줄)으로 나눈다.
- 부제: `현지 가게 이름 · 동네 · 가성비/보통`. 일정에 들어간 날짜 배지.
- 본문: 사진 + 정보 표(주소, 영업시간, 전화, 특징, 가격대) + 지도.
- 짧은 여행(해남)은 끼니 칸을 먼저 보여 주고, 그 아래 `후보지` 섹션을 구분선으로 나눈다.

## 6. 정보 탭

상단 세그먼트 탭 `여행 · 음식 · 검색`.

- **여행**
  - 여행 정보: 항공(편명·출발 시각 표), 숙소(주소·체크인/아웃·셔틀 시간표·지도), 비상 연락처, 여권/입국 규정, 데이터(eSIM, 왜 그 일수인지), 학교(체험학습 신청·결과보고서 준비)
  - 여행 팁: `처음이라면 먼저 읽기`, `식사`, `돈 아끼기`, `날씨·복장`, `안전(아이가 먼저 할 행동)`, 현지 행사, `용어 풀이`, `간단한 현지어`(말과 발음 / 뜻·쓰는 때 표)
- **음식**: 식사 / 길거리 간식 / 달콤한 것 / 마실 것. 카드마다 사진, **"주문할 때 보여주기" 현지어 큰 글씨**, 어떤 음식, 먹는 곳, 아이 참고, 가격, **`먹어봄` 토글**(누르면 카드 테두리 강조, 폰에 저장).
- **검색**: 일정 카드·장소·음식·맛집·팁·준비물을 한 번에 찾는다. 일정 결과를 누르면 그날 그 카드로 이동해 테두리로 표시.

## 7. 준비 탭

- 사람별 탭(예: 아이 / 엄마) + 각 사람 `완료 수/전체` 표시 + 진행 막대.
- 그 사람 소개 한 줄 (`아이 짐은 아이가 직접 싸고, 엄마가 한 번만 확인한다.`).
- 시기별 접는 묶음(`여행 전 준비`, `출발 당일` …), 묶음마다 `3/12` 또는 `완료`.
- 체크는 **localStorage**에 저장(키 접두어는 여행지별: `ist.checks` 같은 식), 맨 아래 `체크 모두 해제` + 확인 단계.
- 옷 개수, 날씨에 맞는 겉옷, 현지 복장 규칙, 보조배터리 기내 반입처럼 구체적으로 적는다.

## 8. 문장 쓰는 법

- 한국어, 짧은 평서문 `~한다`로 끝낸다. (`정원에서 커피와 디저트를 나눠 먹으며 쉰다.`)
- 낯선 말은 처음 나올 때 괄호로 풀어 쓴다: `보스포루스 해협(유럽과 아시아 사이의 좁은 바닷길)`, `그랜드 바자르(큰 지붕 시장)`.
- 장소 이름은 한국어 표기 + 현지어 원어를 함께 둔다 (`쉴레이마니예 모스크` / `Süleymaniye Camii`).
- 아이(초등~중학생)가 읽어도 이해되게 쓴다. 아이 이름이 정해져 있으면 `○○이 미션`, `○○이 참고`처럼 이름을 넣는다.
- 숫자는 구체적으로: 시간 범위(`15~20분`), 거리(`약 1.2km`), 요금, 운영 시간.
- 확실하지 않은 정보는 `출발 전 확인`, `현지 확인`이라고 붙인다. 지어내지 않는다 — 운영 시간·요금·교통편은 웹에서 확인하고, 확인 못 한 건 그렇게 적는다.

## 9. 데이터 구조 (이스탄불 코드 기준)

`istanbul/index.html`의 `<script>`는 데이터 → 렌더 순서다. 새 여행은 데이터 부분만 바꾼다.

| 부분 | 내용 |
|---|---|
| `I=[...]`, `MEDIA`, `PHOTOS` | base64 사진 |
| `HOTEL`, `HQ` | 숙소 이름(강조 표시용), 지도 검색어 |
| `L` | 외부 참고 링크 `[이름, URL]` |
| `day(id, ym, d, 요일, 제목, 부제, [s(...)...], [], 비용)` | 하루 일정 |
| `s(time, title, {move, moveAt, route, stay, key, q, map, placeId, rel, photos})` | 정류장 카드. `move`·`moveAt`이 카드 **위**의 이동 칩이 된다 |
| `DEPARTURES` | 날짜별 이동 칩의 출발지 짧은 이름 |
| `LOCAL`, `MAP_COORDS` | 장소별 현지어 검색어, 좌표 |
| `place({id, g, t, s, star, intro, about, fun, mission, how, stay, rows, caution, lk})` | 장소/맛집(`tab:"맛집"`) |
| `food({id, group, title, local, desc, where, note, price, photo})` | 음식 |
| `tip(id, 제목, 부제, blocks)` / `add({tab:"팁"...})` | 정보 탭 |
| `CHECK` | 사람별 체크리스트 `[묶음 이름, [항목...]]` |
| `travelByDay` | 날짜별로 붙일 이동 정보 id |
| `CHECKS_KEY` 등 | localStorage 키 — **여행지마다 접두어를 바꾼다** |

`stay`에 숫자가 없으면 체류 시간 줄은 숨겨진다. `rel`에 넣은 id가 "함께 보기"가 된다.

## 10. 작업 순서

1. 먼저 물어볼 것: 여행지, 날짜, 같이 가는 사람(아이 이름·나이), 숙소, 항공/교통편 예약 상태, 꼭 가고 싶은 곳.
2. 날짜별로 동네·테마를 정하고, 카드–이동–카드 동선을 표로 먼저 보여 주고 확인받는다.
3. `istanbul/index.html`을 `<새 폴더>/index.html`로 복사 → 데이터 교체 → 이스탄불 전용 문구(셔틀, 공화국의 날 등)와 localStorage 키 정리.
4. 새 `icon.svg` (단순한 한 색 실루엣).
5. 폰 폭(390px)과 다크 모드에서 Playwright로 스크린샷을 찍어 확인한다: 이동 칩 시각 계산, 사진 레이아웃, 가로 스크롤 없음.
6. 커밋·푸시.
