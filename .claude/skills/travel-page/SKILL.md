# 여행 페이지 만들기 가이드

이 저장소의 여행 페이지는 **폰에서 여행 중에 꺼내 보는 한 장짜리 앱**이다.
가장 공들인 기준 작품은 `istanbul/index.html`(해외 12일)이고, `haenam/index.html`은 국내 1박 2일 버전이다.
새 페이지는 **이스탄불 파일을 복사해 데이터만 바꾸는 방식**으로 만든다. CSS와 렌더 코드를 새로 짜지 않는다. 그래야 UI가 똑같이 나온다.

이 문서의 1~9장은 **어떤 여행이든 지키는 기본 방식**이다.
누구와 가느냐에 따라 달라지는 부분은 **10장**에 따로 모았다.

---

## 0. 기본 원칙 — 이 여행 페이지가 좋아하는 것

1. **동선이 한눈에 보여야 한다.** 일정은 "장소 카드 → 이동 → 장소 카드"로 흐르고, 이동 자체도 하나의 정보 칸으로 다룬다.
2. **시간 계산이 실제로 맞아야 한다.** 출발 시각, 이동 시간, 체류 시간이 서로 맞물리고, 대기·환승·오르막까지 반영한 현실적인 범위를 쓴다.
3. **왜 그 순서인지 적는다.** 운영 시작 시각, 휴무, 셔틀 시간표, 해 지는 시각 같은 이유를 메모에 남긴다.
4. **틀어질 때를 대비한다.** 대안 식당, 택시 대안, "일정이 밀리면 ○○부터 뺀다" 같은 플랜 B를 둔다.
5. **결론을 먼저 말한다.** 교통수단 비교도 `결론: 메트로.`로 시작하고 근거 표를 뒤에 둔다.
6. **확정과 미정을 구분한다.** `예매 완료`, `요청 중 (안 되면 …)`, `점심 예정`, `· 선택`, `출발 전 확인`을 분명히 적는다.
7. **무리하지 않는다.** 쉬는 칸(카페·차·호텔 휴식)을 일정 안에 넣는다. 무료 명소와 동네 산책 위주로 하고, 유료는 꼭 볼 곳만 고른다.
8. **현장에서 바로 쓸 수 있어야 한다.** 지도 버튼, 전화 걸기 링크, 현지어 주문 문구, 오프라인에서도 열리는 단일 파일.

## 1. 파일 구성

```
<여행지>/
  index.html   ← 모든 것이 들어 있는 단일 파일 (CSS·JS·데이터·사진)
  icon.svg     ← 바로가기 아이콘. 그 여행지를 상징하는 단순한 실루엣 하나 (이스탄불=모스크, 해남=닻)
```

- 폴더 이름은 영문 소문자 (`istanbul`, `haenam`, `jeju`, `kyoto` …).
- 사진은 **base64로 HTML 안에 넣는다**. 여행지에서 데이터가 약해도 열리게 하기 위해서다. 사진은 긴 변 900~1200px 정도의 JPEG로 줄인다.
- 외부 스크립트나 폰트에 의존하지 않는다. 오프라인에서도 전부 동작해야 한다.
- `<title>`은 여행지 이름. `icon.svg`를 `rel="icon"`과 `rel="apple-touch-icon"` 둘 다에 연결해 홈 화면 추가가 되게 한다.

## 2. 전체 UI 뼈대

- 모바일 우선, 본문 최대 폭 **720px**(휴대폰에서는 꽉 채우고, 태블릿에서도 넓게 본다. 아래 탭 바도 같은 폭), 좌우 여백 16px, 아이폰 안전 영역(`env(safe-area-inset-*)`) 처리.
- **맨 위 앱 이름**(여행지 이름): 18px 굵게, 가운데, 양옆에 가는 두 줄 장식. 위에 고정하지 않는다. 그 아래 소개 줄·사용법 안내·주의 문구·각주 같은 부연설명은 쓰지 않는다.
- **하단 탭 5개** (아이콘 + 글자). 바닥에 딱 붙인 막대로 둔다: 둥근 모서리 없이 위쪽 가는 선 하나, 홈 바 영역만큼만 안쪽 여백. 마지막으로 본 탭과 서브 탭은 이 기기에 기억한다.
  - 긴 여행: `일정 · 장소 · 맛집 · 정보 · 준비` (이스탄불)
  - 1박 2일처럼 짧은 국내 여행: `첫째날 · 둘째날 · 체크리스트` (해남. 날짜를 탭으로 바로 보여 주고 날짜 스트립은 두지 않는다). 미리 많이 알아봐야 하는 해외여행과 달리 **장소·맛집·정보 탭을 두지 않고 일정에 다 담는다.** 장소 정보 · 후보 식당 · 열차 · 렌터카 · 숙소 · 옷차림 · 해 뜨고 지는 시각은 관련 일정 카드 맨 아래 ＋ 줄로 붙인다(3-3). 체크리스트 탭에는 체크리스트 카드만 둔다. 화면 모양은 이스탄불과 같다(2-1).
- 라이트/다크 모드 둘 다 지원 (`prefers-color-scheme`).
- 색: 칙칙하지 않게 **밝고 산뜻하게**. 배경은 옅은 회색 `#EDF1F4`(다크 `#060809`), 흰 카드(다크 `#1C2226`) + 옅은 테두리 `#E0E6EA` + 아주 옅은 그림자. 카드가 배경에서 또렷이 떠 보여야 한다. 강조색은 **맑은 청록 `#0A7975`** (다크 `#4DB6B6`). 강조색 글씨는 흰 바탕·옅은 강조 바탕(`--accent-soft`) 위에서 대비 4.5:1 이상을 지킨다. 여행지에 맞게 바꿔도 되지만 강조색은 한 가지만 쓴다. 빨강은 주말과 미정 끼니에만 쓴다.
- 글꼴: Pretendard → Apple SD Gothic Neo → Noto Sans KR. `word-break: keep-all`.
- 글자 크기는 `CLAUDE.md`의 디자인 규칙대로 **4단계 토큰만** 쓴다: `--fs-xl` 20 (현지어 주문 문구처럼 꼭 커야 하는 것만. **20px이 최대, 24px 이상은 어디에도 쓰지 않는다**) / `--fs-l` 18 (카드 제목, 날 머리, 일정 카드 시각·제목) / `--fs-m` 16 (본문) / `--fs-s` 14 (설명, 메모, 표, 탭, 날짜 라벨). `font-size`에 px 숫자를 직접 쓰지 않는다.
- 탭별 스크롤 위치를 기억한다. 스크롤 자체는 브라우저 기본 그대로 두고, `100dvh` 최소 높이나 스크롤 중 `scrollTo` 같은 꼼수는 쓰지 않는다. 화면 이동 없이 카드 안에서 펼치는 방식을 선호한다.
- 날짜는 연도와 요일 없이 `월.일`로 쓴다: `10.25`, `11.1`(앞자리 0 없이). 날 머리만 `10월 25일 일요일`처럼 글로 쓴다(해남은 한 줄 날 머리라 `11.7 토`).
- 지도·전화·일정 바로가기는 **글자 대신 아이콘**이다(원형 44px 버튼, 일정은 달력 아이콘 + 날짜). "지도 보기" 같은 글자 링크는 쓰지 않는다.
- 기록 기능은 **준비 탭 체크 표시만** 둔다(7장). 먹어봄 같은 다른 기록 기능은 두지 않는다. 내용 추가·수정은 Claude에게 시키고 앱에 수정 버튼을 두지 않는다.

### 2-1. 장소·맛집·정보·준비 화면: 카드 = 머리 + ＋ 줄

- **검색창**(필요한 탭만): 그 탭 화면 맨 위에 하나. 검색어가 있으면 고른 카드 대신 결과 카드를 보여 준다.
- **서브 탭(알약)**: 카드가 많을 때만 검색창 아래. 여러 줄로 감싸 **모든 알약이 한눈에** 보인다. 가로로 밀지 않고, 위에 고정하지 않는다. 고른 카드 하나만 보인다.
- **카드 머리**: 제목(18px 굵게, **강조색**) + 오른쪽 회색 알약 배지(`16곳`, `8가지`) + 꼭 필요할 때만 아래 회색 요약 한 줄. `일정에 들어간 곳 14곳` 같은 쓸데없는 요약은 달지 않는다. 머리 아래 가는 선.
- **＋ 줄**: 카드 폭을 꽉 채우고, 줄 사이는 가는 선 하나. 두 줄 모양이다: 왼쪽 위 이름(16px 굵게), 그 아래 회색 요약(14px, 잘리지 않게 **둘째 줄**), 오른쪽 위 회색 날짜(`10.25`, 여럿이면 한 줄에 하나씩 쌓기), 그 아래 **가운데** ＋. ＋ 칸은 폭이 같아(`--side-w`, 날짜 하나 폭) 모든 줄의 ＋가 한 세로줄에 선다. 최소 44px. 접힌 줄에는 내용 미리보기를 넣지 않는다.
- **펼치면**: 한 줄 소개 → 사진 → 아이콘(오른쪽 정렬, 전화 · 내비(국내 렌터카 여행, 티맵) · 일정 날짜 · 지도 순서. 지도는 항상 맨 오른쪽) → 제목 붙은 덩어리(어떤 곳, 메모, 정보, 주의할 점 …). **안쪽 ＋ 줄 없이 한 번에 다 보인다**: 덩어리 위에 14px 회색 굵은 작은 제목, 덩어리 사이 12px. 상자 안에 상자를 넣지 않는다.
- **펼친 표시는 어디서나 같다**: ＋가 －로 바뀌고, 제목 줄에 옅은 배경(`--disclosure-bg`)을 깔고, 펼친 범위의 왼쪽 끝(카드 가장자리)에 강조색 막대 3px. 펼친 제목은 읽는 동안 화면 위에 붙어 있고, 눌러 접으면 그 자리로 돌아온다.
- 알약 모양은 서브 탭과 카드 머리 배지에만 쓴다. 카드 모서리 16px, 안쪽 여백 20px, 카드 사이 16px.

## 3. 일정 화면 — 가장 중요한 부분

### 3-1. 날 머리

1. **날짜 스트립**: 맨 위에 모든 날짜를 요일+숫자 버튼으로 나열한다. 선택된 날은 강조색으로 채우고, **토·일은 빨간색**.
2. **날 머리는 두 줄만, 가운데 정렬, 둘 다 18px**. 제목은 작게, 군더더기 없이. 상자형 날짜 블록, 큰 제목, 출발·체크인 같은 부제는 넣지 않는다.
   - 첫 줄: 날짜·지역, 강조색: `11월 7일 토요일 · 해남`
   - 둘째 줄: 그날 제목(테마): `베이올루와 쥐쿠르주마`, `유럽에서 아시아로`, `해남의 역사와 땅끝 바다`
   - 해남(날짜 스트립 없이 탭이 날짜인 짧은 여행)은 **한 줄**로 더 단순하게: 회색 `11.7 토` · 굵은 제목 `해남의 역사와 땅끝 바다`. 강조색과 지역 이름은 넣지 않는다.
3. **플랜 B는 따로 모아 두지 않고 그 카드 메모 끝에 쓴다**(날 아래 `알아둘 것` 카드 없음): 우수영 카드에 `일정이 밀리면 여기는 빼고 목포역에서 해남읍으로 바로. 땅끝탑 시간을 먼저 지키기.`
4. **이동 정보**(공항 가는 법, 교통카드 등)는 날 아래에 몰아 두지 않는다. 이어지는 일정 카드 맨 아래에 ＋ 줄로 붙인다(3-3). 맨 아래에 `‹ 10.24` `10.26 ›` 이전/다음 날 버튼.

### 3-2. 카드 – 이동 – 카드 동선 (핵심 형식)

하루는 **장소 카드 → 이동 → 장소 카드 → 이동 …** 으로 세로로 흐른다.

```
┌────────────────────────────┐
│ 09:00  세인트 안투안 성당          │
│ 일요일 10:00 영어 미사 전, 조용히 둘러본다. │
│ [사진]                      │
│ 체류 45분               (i)(📍) │
└────────────────────────────┘
  ┊ 09:55 출발                         ← 이동: 첫 줄 출발 시각
  ┊ 이스티클랄 거리를 따라 도보 5분 · 약 400m  ← 둘째 줄부터 회색 설명
┌────────────────────────────┐
│ 10:00  아스말르메스짓 골목 산책 …       │
```

- **하루는 항상 카드로 시작한다.** 첫 카드 위에는 이동 글을 두지 않는다. 숙소·역에서 첫 카드로 가는 길은 그 카드의 `가는 길` 줄(`route`)에 `09:30 수원역 출발 · 4100번 공항리무진으로 제2터미널 직통`처럼 쓴다.
- 카드 사이는 왼쪽의 **세로 점선**(`--journey-line`)으로 잇고, 그 옆에 이동 글을 둔다. 첫 줄은 출발 시각(`09:20 출발`, 굵게), **둘째 줄부터 회색 설명**. 오른쪽도 왼쪽 들여쓰기(점선까지 46px)만큼 비워 글이 오른쪽 끝까지 가지 않게 한다. 알약 칩은 쓰지 않는다.
- 이동 문장은 항상 **`{출발 시각} 출발` / `{수단과 경로} · {소요 시간} · {거리}`** 순서다. 아래 예의 `·` 앞이 첫 줄이다.
  - `08:40 출발 · 호텔에서 이스티클랄 방면 도보 15~20분 · 약 1.1km`
  - `09:30 출발 · 호텔→탁심 도보 15~20분 → M2 베즈네질레르 7분 → 오르막 도보 12분 · 열차 대기 포함 총 40~55분`
  - `13:55 출발 · 언덕을 넘어 도보 30분 안팎 · 약 2km · 오르막 포함 (택시 10분)`
  - 국내 렌터카: `09:50 출발 · 차 50분` / 열차: `열차 2시간 19분 · 09:15 목포역 · 도보 5분`
- 환승은 `→`로 잇고, 구간마다 시간을 붙인다. **대기 시간을 포함한 총 소요**를 범위로 적는다.
- 오르막·내리막, 택시 대안, 막차·셔틀 시각처럼 **실제로 발목을 잡는 제약**을 칩이나 메모에 꼭 적는다.
- 시각 계산이 맞아야 한다: `다음 카드 시각 ≈ 출발 시각 + 이동 시간`, `출발 시각 ≈ 이전 카드 시각 + 체류 시간`.
- 페리·예배·노을처럼 시각이 유동적인 뒤쪽 일정은 `도착 직후`, `모스크 후`, `페리 시각에 맞춰`처럼 **상대 시각**으로 쓴다.

### 3-3. 장소 카드 안쪽

- 카드는 **시간과 목적이 먼저, 사진은 그 아래**다. 순서: 머리줄(시각 + 제목) → 메모(왜 가는지·무엇을 하는지) → 사진 → 체류 시간 + 아이콘.
- 머리줄: **굵은 강조색 시각(18px)** + 제목(18px). 시각은 **시작 시각만** 짧게 보여 준다(`11:00~11:20 예상` → `11:00`). 범위나 "예상"은 메모에 적는다.
- **사진**은 둥근 모서리로 카드 안쪽 폭에 맞춘다: 1장(16:9), 2장(나란히), 3장(위 1장 크게 + 아래 2장).
- 그 카드에 연결된 **장소 · 맛집 · 음식 · 팁 · 이동 정보**(공항에서 호텔, 교통카드, 구시가지 가는 법 …)는 `placeId`·`rel`에 id를 넣으면 카드 맨 아래, 체류·아이콘 줄 밑에 카드 폭 ＋ 줄로 붙는다(카드 자신의 장소가 맨 위). 다른 탭으로 보내지 않고 **그 자리에서 펼친다.** 펼친 모양은 장소·맛집 탭의 ＋ 줄과 같다(옅은 배경 · 왼쪽 강조색 막대 · 한 번에 다 보이는 내용). 카드에 이미 있는 사진 · 지도는 다시 넣지 않고, 일정 날짜 버튼은 다른 날 것까지 모두 두지 않는다(날짜 버튼은 장소·맛집 탭에서만).
- 맨 아래 줄: 왼쪽 회색 `체류 45분`, 오른쪽 📍 지도 아이콘(원형). 장소 · 맛집 탭에서 일정 날짜 버튼을 누르면 그날 일정의 그 카드로 가서 잠깐 테두리로 표시한다.
- 끼니도 하나의 정류장이다. 제목은 **`점심: 식당명`**, **`간식: …`** 으로 쓴다. 카페·디저트·차 한잔도 정류장으로 넣는다.
- 아직 식당을 못 정한 끼니는 `점심 예정`으로 쓰고 **빨간 제목**(해남의 `chg`)으로 표시한다. 메모에는 `후보: A - 대표 메뉴. 대기가 길면 B로.`처럼 적는다.
- 빼도 되는 일정은 제목 끝에 **`· 선택`** 을 붙인다 (`땅끝 일출 · 선택`).
- 하루의 처음과 끝은 숙소다 (`호텔 아침`, `호텔 도착`, `체크인`). 숙소 이름은 본문에서 강조색으로 표시한다.
- 예약된 교통편은 메모에 편명·좌석까지 적는다: `KTX-산천 605, 예매 완료.`, `좌석 01·02번(맨 앞 2인석)`.
- 일행이 따로 움직이는 구간은 카드를 나눠 쓴다: `19:55 일행 1명 열차 출발` → `20:22 나머지 일행 KTX 출발`.
- 지도 링크: 해외는 구글 지도(현지어 장소명으로 검색), 국내는 네이버 지도.

### 3-4. 일정 짜는 방식 (내용 면)

- 하루 정류장은 **4~10곳**. 걸어서 이어지는 동네 단위로 묶고, 하루에 지역 하나나 테마 하나를 잡는다.
- 도착 다음 날은 늦게 시작한다. 반나절마다 카페·차·바닷가처럼 쉬는 칸을 하나씩 넣는다.
- **해 지는 시각과 해 뜨는 시각을 일정에 맞춘다.** 노을 명소는 일몰 시각에 도착하게 배치한다 (`땅끝탑 17:30 / 일몰 17:36 전후`, `모다 해안 18:05 무렵 노을`).
- 요일·공휴일·휴무·운영 시작 시각·셔틀 시간표·예배 시간을 반영해 순서를 정하고, 그 이유를 메모에 적는다.
  예) `호텔 셔틀은 10:00부터 운행해 09:30 출발에는 탈 수 없어 도보와 지하철로 간다.`
  예) `10월 29일은 국경일이라 박물관과 바자르는 빼고 야외 일정만 잡는다.`
- 붐빔을 예상해 적는다: `단풍철 토요일이라 주차장이 붐빌 수 있음`, `일요일이라 대기 감안`.
- 안전 메모를 남긴다: `어두울 때 데크길은 가지 않기`, `해 진 뒤라 휴대폰 손전등`.
- 렌터카 여행이면 인수·반납·주유도 정류장으로 넣고 주차 정보를 적는다 (`차 바깥 상태를 사진으로 남기기`, `첫 1시간 무료`).

## 4. 장소 탭

2-1의 구조를 따른다: 검색창 → 그룹 서브 탭(도서관 / 공원 / 거리·동네 / 모스크·시장 / 쇼핑 / 유료 명소) → 고른 그룹 카드 하나.
＋ 줄은 이름 + 둘째 줄 회색 부제(현지어 이름 또는 동네) + 오른쪽 위 일정 날짜(`10.25`). 별점(★1~5)을 데이터로 가진다.

펼친 본문 순서는 고정이다:

1. **한 줄 소개**
2. 사진
3. 아이콘: 일정 날짜(누르면 그날 일정으로), 지도(맨 오른쪽)
4. 작은 제목을 단 덩어리: **어떤 곳**(해남처럼 **왜 가는지**를 붙여도 좋다. 재미있는 이야기 2~3개도 여기에 이어 쓰고 칸을 따로 두지 않는다) · 메모 · **정보**(현지 이름 · 주소 · 운영 · 요금 · 전화 · 가는 법 · 머무는 시간) · **주의할 점**

## 5. 맛집 탭

- 2-1의 구조를 따른다: 검색창(맛집) → 서브 탭 → 카드 하나.
- 서브 탭은 **동네별 식당 묶음**만 둔다. 지역 카드 머리의 회색 요약에는 그 지역 설명 한 줄(어떤 동네인지 + 들어 있는 동네 나열, `RESTAURANT_REGION_GROUPS`의 `note`)을 둔다: `탁심 광장 주변 번화가. 이스티클랄 · 지한기르 · 페라 · 니샨타시`. 음식 묶음(식사 / 길거리 간식 / 달콤한 것 / 마실 것)은 맛집 탭이 아니라 **정보 탭** 서브 탭에 둔다(6장).
- 식당 줄: 이름(첫째 줄) + 회색 `현지 가게 이름 · 동네 · 가성비/보통 · 평점 4.4`(둘째 줄) + 일정 날짜. 펼치면 한 줄 소개(또는 특징) → 사진 → 아이콘(전화 · 일정 날짜 · 지도) → 어떤 곳 · 정보 · 주의할 점 덩어리.
- 음식 줄(정보 탭): 이름 + 회색 현지어 이름(둘째 줄). 펼치면 어떤 음식 → 사진 → **"주문할 때 보여주기" 현지어 큰 글씨(20px)** → 먹는 곳 · 참고 · 가격 덩어리.
- 짧은 여행(해남)은 맛집 탭 없이 **끼니 카드 맨 아래에 후보 식당을 ＋ 줄로 나열**한다(대표 후보가 먼저, 대안이 뒤). 일정의 끼니 카드는 `rel`로 후보 식당과 꼭 연결한다. 해남 장소·식당은 내용이 짧아 **작은 제목도 없이** 바로 이어 쓴다: `왜 가는지` 한 줄 → 사진 → 아이콘 → 설명과 이야기 → 메모(점 목록) → 정보(표). 덩어리 사이는 12px. 카드 자신의 장소를 펼치면 카드에 이미 있는 사진·내비·지도는 다시 넣지 않는다(전화만).

## 6. 정보 탭

맨 위에 **전체 검색창**, 그 아래 서브 탭 `여행 정보 · 여행 팁 · 식사 · 길거리 간식 · 달콤한 것 · 마실 것`(음식 묶음은 5장의 음식 줄 모양). 항목마다 ＋ 줄이고, 제목이 붙은 내용 덩어리는 작은 제목을 달고 한 번에 다 보인다.

- **여행 정보**
  - 항공·열차: 구간·편명·출발 표. 열차는 승차권 모양 카드(시각–역 두 열).
  - 숙소: 주소·전화·위치(주요 명소까지 걸어서 몇 분)·체크인/아웃·주차·아침·셔틀 시간표·지도
  - 렌터카·택시: 인수/반납 시각과 장소, 연료 규정, 택시 호출 시각
  - 해 뜨고 지는 시각, 날씨·옷차림(대략 기온 + "출발 전 예보 확인")
  - 비상 연락처는 **`tel:` 링크**로 눌러서 바로 전화
  - 해외: 여권·입국 규정, 데이터(eSIM, 왜 그 일수인지), 화폐, 시차
- **이동 안내** 쓰는 법
  - 여러 방법 비교: `결론: …` 한 줄 → 방법·환승·걸리는 시간 표 → 방법별 설명
  - 처음 하는 이동: **`○○ 따라하기`** 번호 목록 + **`막혔을 때`** 대처 목록
  - 운임처럼 자주 바뀌는 값에는 `공시 기준. 재확인.` 메모를 붙인다
- **여행 팁**: `처음이라면 먼저 읽기`(기본 몇 가지), `식사`, `돈 아끼기`, `날씨·복장`, `안전`, 현지 행사, `용어 풀이`, `간단한 현지어`(말과 발음 / 뜻·쓰는 때 표)
- **검색**: 일정 카드·장소·맛집·음식·팁·이동·준비물을 한 번에 찾는다. 결과는 종류별 카드로 보여 준다. 일정 결과를 누르면 그날 그 카드로 이동해 테두리로 표시한다.

## 7. 준비 탭

- 항목마다 **체크 칸**을 둔다. 체크하면 강조색 네모에 흰 체크, 글은 회색 취소선. 체크는 이 기기에 저장한다(`CHECKS_KEY`). 사람마다 따로 챙기면 사람별 서브 탭을 둔다.
- 시기별 묶음 + 기한을 카드 제목으로: `출발 전 · 11/6까지`, `짐`, `출발 당일`. 배지는 체크한 수/전체 `3/21`.
- 항목에 보조 설명을 붙일 수 있다: `KTX 표 확인 — 11/7 605편, 11/8 632편`.
- 예약 확인, 식당 영업 확인, 미정 끼니 정하기 같은 **할 일**도 항목으로 넣는다.
- 옷 개수, 날씨에 맞는 겉옷, 현지 복장 규칙, 보조배터리 기내 반입처럼 구체적으로 적는다.

## 8. 문장 쓰는 법

- 한국어, 짧은 평서문. 이스탄불은 `~한다`(`정원에서 커피와 디저트를 나눠 먹으며 쉰다.`), 해남은 메모체(`차 바깥 상태를 사진으로 남기고 짐 싣기.`). 한 페이지 안에서는 하나로 통일한다.
- 낯선 현지 용어는 처음 나올 때 괄호로 풀어 쓴다: `보스포루스 해협(유럽과 아시아 사이의 좁은 바닷길)`, `그랜드 바자르(큰 지붕 시장)`. 정보 탭에 `용어 풀이`를 모은다.
- 장소 이름은 한국어 표기와 현지어 원어를 함께 둔다 (`쉴레이마니예 모스크` / `Süleymaniye Camii`).
- 숫자는 구체적으로 쓴다: 시간 범위(`15~20분`), 거리(`약 1.2km`), 요금, 운영 시간, 전화번호.
- 확실하지 않은 정보에는 `출발 전 확인`, `현지 확인`을 붙인다. 지어내지 않는다. 운영 시간·요금·교통편·해 지는 시각은 웹에서 확인하고, 확인 못 한 건 그렇다고 적는다.

## 9. 데이터 구조 (이스탄불 코드 기준)

`istanbul/index.html`의 `<script>`는 데이터 → 렌더 순서다. 새 여행은 데이터 부분만 바꾼다.

| 부분 | 내용 |
|---|---|
| `I=[...]`, `MEDIA`, `PHOTOS` | base64 사진 |
| `HOTEL`, `HQ` | 숙소 이름(강조 표시용), 지도 검색어 |
| `L` | 외부 참고 링크 `[이름, URL]` |
| `day(id, ym, d, 요일, 제목, 부제, [s(...)...], 비용)` | 하루 일정. 날 메모는 두지 않는다: 플랜 B · 투어비 · 확인할 것은 해당 카드의 `key` 끝에 쓴다 |
| `s(time, title, {move, moveAt, route, stay, key, q, map, placeId, rel, photos})` | 정류장 카드. `move`·`moveAt`이 카드 **위**의 이동 칩이 된다 |
| `DEPARTURES` | 날짜별 이동 칩의 출발지 짧은 이름 |
| `LOCAL`, `MAP_COORDS` | 장소별 현지어 검색어, 좌표 |
| `place({id, g, t, s, star, intro, about, memo, how, stay, rows, caution, lk})` | 장소/맛집(`tab:"맛집"`) |
| `food({id, group, title, local, desc, where, note, price, photo})` | 음식(정보 탭 서브 탭 `FOOD_GROUP_NAMES`) |
| `tip(id, 제목, 부제, blocks)` / `add({tab:"팁"...})` | 정보 탭 |
| `add({tab:"이동"...})` | 이동 정보. 일정 카드 `rel`에 id를 넣으면 그 카드 맨 아래 ＋ 줄 |
| `CHECK` | 준비 목록 `{person, intro, groups:[[묶음 이름, [항목...]]]}` (체크 id는 사람 `idKey` + 항목 글로 만든다) |
| `TAB_KEY`, `SUB_KEY`, `CHECKS_KEY` | 마지막 탭·서브 탭, 준비 체크를 기억하는 localStorage 키. **여행지마다 접두어를 바꾼다** (`ist.tab`, `ist.checks`) |
| `RESTAURANT_REGION_GROUPS` | 맛집 동네별 묶음 = 맛집 탭 서브 탭 |

- `stay`에 숫자가 없으면 체류 시간은 숨겨진다. `placeId`·`rel`에 넣은 id가 일정 카드 맨 아래 ＋ 줄(장소·맛집·음식·팁·이동)이 된다.
- `place()`·`food()`·`wishlistRestaurant()`는 펼친 내용을 블록으로 만든다: 제목(`h`) 없는 블록은 위에 그대로, `{t:"actions"}` 자리에 지도·전화·일정 아이콘, 제목 있는 블록은 작은 제목(`h4.sec`) + 내용. 모두 데이터 순서대로 한 단계에 그린다. 팁·이동 항목도 같은 규칙으로 그려진다.
- 해남에서 가져올 것: 미정 끼니 빨간 제목(`chg`), 열차 승차권(`tk`), 티맵 내비 아이콘. 해남도 이스탄불과 같은 CSS·그리기 코드를 쓰고, 이동·숙소·옷차림·해 뜨고 지는 시각은 관련 일정 카드 맨 아래 ＋ 줄로 붙인다. 짧은 국내 여행이라 펼친 내용에 작은 제목도 달지 않는다.
- 음식의 `아인이 참고` 같은 동행 전용 칸은 10장에 따라 이름을 바꾸거나 뺀다. 장소 본문에 미션 칸은 두지 않는다.

## 10. 동행에 따라 바꾸는 부분

1~9장은 그대로 두고, 아래만 여행마다 조정한다. **시작할 때 누구와 가는지 먼저 물어본다.**

| 동행 | 바꾸는 것 |
|---|---|
| **아이와 함께** (이스탄불) | 음식에 `○○이 참고`(미션 칸은 두지 않는다). 설명은 아이가 읽어도 이해되게 쓴다. 안전 팁은 `○○이가 먼저 할 행동`. 준비 탭은 아이/어른 탭을 나누고 아이 짐은 아이가 직접 싼다. 학교 체험학습 신청·결과보고서 준비. |
| **어른끼리·가족 어른** (해남) | `어떤 곳`에 `왜 가는지`를 붙인다. 메모는 짧은 메모체로 써도 된다. 렌터카라면 운전 시간 합계와 교대 운전을 적는다. |
| **부모님·어르신** | 오르막·계단·걷는 거리를 줄이고 택시 대안을 앞에 둔다. 쉬는 칸을 늘리고 화장실·앉을 곳을 메모에 적는다. |
| **일행이 나뉘는 경우** | 귀가·합류 시각이 다르면 카드를 나눠 쓰고(`일행 1명 열차 출발`), 반드시 지켜야 할 시각을 이동 안내에 강조한다. |

- 사람 이름이 정해져 있으면 문장에 이름을 넣는다 (`은영·아인이 탑승`, `로비에서 남편과 만난다`).
- 동행이 바뀌어도 동선 형식, 시간 계산, 플랜 B, 확정·미정 표기는 그대로다.

## 11. 작업 순서

1. 먼저 물어볼 것: 여행지, 날짜, **누구와 가는지**, 숙소, 항공·열차·렌터카 예약 상태, 꼭 가고 싶은 곳과 빼고 싶은 것.
2. 날짜별로 동네·테마를 정하고, 카드–이동–카드 동선을 표로 먼저 보여 주고 확인받는다.
3. `istanbul/index.html`을 `<새 폴더>/index.html`로 복사 → 데이터 교체 → 이스탄불 전용 문구(셔틀, 공화국의 날, 사람 이름 등)와 localStorage 키 정리 → 10장에 따라 동행 전용 칸 조정.
4. 새 `icon.svg` (단순한 한 색 실루엣).
5. 폰 폭(360px)과 다크 모드에서 Playwright로 스크린샷을 찍어 확인한다: 이동 칩 시각 계산, 사진 레이아웃, 가로 스크롤 없음.
6. 커밋하고 `main`에 푸시한다.
